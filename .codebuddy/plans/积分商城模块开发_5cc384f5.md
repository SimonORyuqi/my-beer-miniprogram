## 用户需求分析

### 核心功能需求

1. **积分商城页面**：从首页"积分商城"按钮点击后跳转进入
2. **用户积分展示**：显示用户当前积分余额
3. **积分兑换商品展示**：显示可用积分兑换的优惠券商品，包含完整信息（名称/类型/面值/有效期）
4. **积分明细查询**：提供积分明细查询按钮，支持筛选（获得积分、消耗积分、过期积分）

### 技术约束

- 数据来源：先使用本地存储模拟数据，后续对接CloudBase后端API
- 遵循现有项目规范（UI配色、代码结构）
- 参考现有vip/recharge和vip/consume页面设计模式

### 预期效果

- 用户从首页点击"积分商城"按钮后，跳转到积分商城页面
- 页面顶部显示用户当前积分余额
- 页面中部展示可兑换的优惠券商品列表
- 页面提供"积分明细"入口按钮，点击后查看积分明细记录

## 技术实现方案

### 技术栈

- **前端框架**：微信小程序原生开发（WXML/WXSS/JS/JSON）
- **数据存储**：wx.getStorageSync/wx.setStorageSync（本地存储模拟）
- **UI规范**：遵循项目现有规范（主色#D4A017、背景色#FFF8F0、卡片色#FFFFFF）

### 页面结构设计

#### 新增页面

1. **积分商城主页**：`pages/points/mall/`

- 显示用户当前积分
- 展示可兑换的优惠券商品列表
- 提供"积分明细"入口按钮

2. **积分明细页面**：`pages/points/detail/`

- 展示积分明细记录
- 支持筛选：全部/获得/消耗/过期

#### 修改文件

- 修改`goToPoints()`方法，从显示提示改为页面跳转

- 添加积分明细记录数据

### 数据结构设计

#### 积分兑换商品数据格式

```javascript
pointsProducts: [
  {
    id: 'p001',
    name: '满100减20优惠券',
    type: '满减券',
    faceValue: 20,
    minAmount: 100,
    pointsCost: 200,
    validityDays: 30,
    description: '全场通用，满100元可用',
    stock: 50
  }
]
```

#### 积分明细记录数据格式

```javascript
pointsRecords: [
  {
    id: 'pr001',
    type: 'earn',  // earn获得/spend消耗/expire过期
    amount: 100,
    description: '充值获得',
    createTime: '2026-05-19 10:00:00'
  }
]
```

### 关键实现逻辑

#### 积分兑换逻辑

1. 检查用户积分是否足够
2. 检查商品库存是否充足
3. 扣除用户积分
4. 减少商品库存
5. 生成兑换记录
6. 更新本地存储数据

#### 积分明细筛选逻辑

- 使用`wx.getStorageSync('pointsRecords')`获取所有记录
- 根据筛选类型（all/earn/spend/expire）过滤数据
- 按时间倒序排列显示

### 性能优化

- 使用本地存储缓存数据，减少重复读取
- 列表渲染使用`wx:key`提升性能
- 图片资源使用懒加载

### 扩展性考虑

- 数据结构设计预留CloudBase对接接口
- 页面组件化设计，便于后续功能扩展
- 遵循现有代码规范，保持代码一致性

### 设计风格

### 积分商城主页设计

#### 1. 积分余额卡片

- 参考vip/recharge页面的账户余额卡片设计
- 使用渐变背景（深棕色到深灰色）
- 居中显示积分余额，使用大号字体
- 右侧提供"积分明细"按钮

#### 2. 兑换商品列表

- 每个商品使用卡片样式展示
- 商品信息包含：名称、类型标签、面值、所需积分、有效期、库存
- 点击"兑换"按钮进行积分兑换
- 兑换按钮根据积分是否足够显示不同状态

#### 3. 空状态设计

- 当无可用兑换商品时，显示空状态提示
- 使用图标+文案的友好提示方式

### 积分明细页面设计

#### 1. 筛选标签栏

- 顶部固定筛选标签：全部/获得/消耗/过期
- 选中状态使用主色#D4A017高亮显示

#### 2. 明细记录列表

- 每条记录显示：积分变化金额、描述、时间、类型标签
- 获得积分显示绿色，消耗显示红色，过期显示灰色
- 按时间倒序排列

#### 3. 空状态设计

- 当筛选结果为空时，显示对应的空状态提示
