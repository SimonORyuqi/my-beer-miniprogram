**文档版本**：V1.0  
**创建日期**：2026-05-15  
**适用系统**：精酿啤酒商城小程序 + 管理后台  

---

## 一、数据库概述

### 1.1 数据库类型
- **主数据库**：MySQL 8.0（关系型数据库）
- **辅助存储**：CloudBase 云存储（商品图片、用户头像）

### 1.2 数据库命名规范
- 表名使用小写字母，单词间用下划线分隔
- 字段名使用小写字母，单词间用下划线分隔
- 索引命名：`idx_表名_字段名`
- 外键命名：`fk_表名_关联表名`

### 1.3 表清单

| 序号 | 表名 | 说明 |
|:----:|------|------|
| 1 | `users` | 用户信息表 |
| 2 | `categories` | 商品分类表 |
| 3 | `products` | 商品表 |
| 4 | `product_specs` | 商品规格表 |

| 12 | `stores` | 门店信息表 |
| 13 | `age_verifications` | 年龄验证记录表 |

## 二、表结构设计

### 2.1 用户信息表 (`users`)

存储用户的基本信息和会员数据。

```sql
CREATE TABLE `users` (
    `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '用户ID',
    `openid` VARCHAR(64) NOT NULL COMMENT '微信OpenID',
    `unionid` VARCHAR(64) DEFAULT NULL COMMENT '微信UnionID',
    `nickname` VARCHAR(50) NOT NULL DEFAULT '' COMMENT '用户昵称',
    `avatar` VARCHAR(500) NOT NULL DEFAULT '' COMMENT '用户头像URL',
    `phone` VARCHAR(20) DEFAULT NULL COMMENT '手机号',
    `member_id` VARCHAR(20) NOT NULL COMMENT '会员编号',
    
    -- 会员信息
    `vip_level_id` VARCHAR(20) NOT NULL DEFAULT 'beer_fan' COMMENT '会员等级ID',
    `vip_name` VARCHAR(20) NOT NULL DEFAULT 'VIP1' COMMENT '会员等级名称',
    `growth_value` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '成长值',
    `points` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '积分余额',
    `balance` DECIMAL(10,2) NOT NULL DEFAULT 0.00 COMMENT '储值余额',
    `total_recharge` DECIMAL(10,2) NOT NULL DEFAULT 0.00 COMMENT '累计充值金额',
    `total_consume` DECIMAL(10,2) NOT NULL DEFAULT 0.00 COMMENT '累计消费金额',
    
    -- 年龄验证
    `age_verified` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否已验证年龄(0-否 1-是)',
    `age_verified_at` DATETIME DEFAULT NULL COMMENT '年龄验证时间',
    
    -- 状态
    `status` TINYINT(1) NOT NULL DEFAULT 1 COMMENT '状态(1-正常 0-禁用)',
    
    -- 时间戳
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_openid` (`openid`),
    UNIQUE KEY `uk_member_id` (`member_id`),
    KEY `idx_vip_level` (`vip_level_id`),
    KEY `idx_created_at` (`created_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户信息表';
```

**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `openid` | VARCHAR(64) | 微信用户唯一标识，必须唯一 |
| `unionid` | VARCHAR(64) | 微信UnionID，绑定多个公众号时需要 |
| `nickname` | VARCHAR(50) | 用户昵称 |
| `avatar` | VARCHAR(500) | 用户头像URL地址 |
| `phone` | VARCHAR(20) | 手机号（用于接收通知） |
| `member_id` | VARCHAR(20) | 会员编号，格式：XXXX XXXX XXXX |
| `vip_level_id` | VARCHAR(20) | 关联vip_levels表 |
| `vip_name` | VARCHAR(20) | 会员等级中文名（冗余字段，避免关联查询） |
| `growth_value` | INT | 成长值，用于计算会员等级 |
| `points` | INT | 积分，可用于积分商城兑换 |
| `balance` | DECIMAL(10,2) | 储值余额，可用于消费 |
| `total_recharge` | DECIMAL(10,2) | 累计充值金额 |
| `total_consume` | DECIMAL(10,2) | 累计消费金额 |
| `age_verified` | TINYINT | 0-未验证 1-已验证 |

```sql
CREATE TABLE `categories` (
```

### 2.3 商品表 (`products`)

存储精酿啤酒商品信息。

```sql
CREATE TABLE `products` (
    `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '商品ID',
    `product_code` VARCHAR(20) NOT NULL COMMENT '商品编码(唯一标识)',
    `name` VARCHAR(100) NOT NULL COMMENT '商品名称(中文)',
    `name_en` VARCHAR(100) NOT NULL DEFAULT '' COMMENT '商品名称(英文)',
    `category_id` BIGINT UNSIGNED NOT NULL COMMENT '所属分类ID',
    `category_code` VARCHAR(20) NOT NULL COMMENT '所属分类代码(冗余)',
    `category_name` VARCHAR(50) NOT NULL COMMENT '所属分类名称(冗余)',
    
    -- 酒款基本信息
    `brewery` VARCHAR(100) NOT NULL DEFAULT '' COMMENT '酿酒厂/品牌',
    `origin` VARCHAR(50) NOT NULL DEFAULT '' COMMENT '产地',
    `abv` DECIMAL(3,1) NOT NULL COMMENT '酒精度数(ABV)',
    `ibu` INT UNSIGNED DEFAULT NULL COMMENT '苦度值(IBU)',
    
    -- 价格信息
    `price` DECIMAL(10,2) NOT NULL COMMENT '基准价格',
    `original_price` DECIMAL(10,2) NOT NULL COMMENT '原价',
    `member_price` DECIMAL(10,2) DEFAULT NULL COMMENT '会员价(可为空表示无会员价)',
    
    -- 评分信息
    `rating` DECIMAL(2,1) NOT NULL DEFAULT 0 COMMENT '评分(0-5)',
    `reviews` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '评价数量',
    
    -- 图片与描述
    `image` VARCHAR(500) NOT NULL COMMENT '主图URL',
    `images` JSON DEFAULT NULL COMMENT '图片列表(JSON数组)',
    `description` TEXT DEFAULT NULL COMMENT '商品描述',
    
    -- 风味信息(JSON格式存储)
    `flavor` JSON DEFAULT NULL COMMENT '风味描述{aroma,taste,finish}',
    `food_pairing` JSON DEFAULT NULL COMMENT '食物搭配建议(JSON数组)',
    
    -- 库存与状态
    `stock` INT NOT NULL DEFAULT 0 COMMENT '总库存数量',
    `sales_count` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '累计销量',
    `is_on_sale` TINYINT(1) NOT NULL DEFAULT 1 COMMENT '是否上架(1-上架 0-下架)',
    `is_featured` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否精选推荐(1-是 0-否)',
    `is_limited` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否限量款(1-是 0-否)',
    
    -- 其他配置
    `sort_order` INT NOT NULL DEFAULT 0 COMMENT '排序序号',
    
    -- 时间戳
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_product_code` (`product_code`),
    KEY `idx_category_id` (`category_id`),
    KEY `idx_category_code` (`category_code`),
    KEY `idx_is_on_sale` (`is_on_sale`),
    KEY `idx_is_featured` (`is_featured`),
    KEY `idx_sort_order` (`sort_order`),
    KEY `idx_created_at` (`created_at`),
    CONSTRAINT `fk_product_category` FOREIGN KEY (`category_id`) REFERENCES `categories` (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='商品表';
```

**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `product_code` | VARCHAR(20) | 商品唯一编码，如 "001", "002" |
| `abv` | DECIMAL(3,1) | 酒精度数，如 6.5 表示 6.5% |
| `ibu` | INT | 苦度单位，国际苦度指数 |
| `flavor` | JSON | 结构：{"aroma":"闻香","taste":"口感","finish":"余韵"} |
| `food_pairing` | JSON | 数组：["汉堡","墨西哥玉米片"] |

### 2.4 商品规格表 (`product_specs`)

存储商品的规格信息（如容量和对应价格）。

```sql
CREATE TABLE `product_specs` (
    `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '规格ID',

    `sort_order` INT NOT NULL DEFAULT 0 COMMENT '排序序号',
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
```

### 2.5 购物车表 (`carts`)

存储用户购物车数据。

```sql
CREATE TABLE `carts` (
    `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '购物车ID',
    `user_id` BIGINT UNSIGNED NOT NULL COMMENT '用户ID',
    `product_id` BIGINT UNSIGNED NOT NULL COMMENT '商品ID',
    `spec_id` BIGINT UNSIGNED NOT NULL COMMENT '规格ID',
    `quantity` INT UNSIGNED NOT NULL DEFAULT 1 COMMENT '购买数量',
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '加入购物车时间',
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_user_product_spec` (`user_id`, `product_id`, `spec_id`),
    KEY `idx_user_id` (`user_id`),
    KEY `idx_product_id` (`product_id`),
    CONSTRAINT `fk_cart_user` FOREIGN KEY (`user_id`) REFERENCES `users` (`id`) ON DELETE CASCADE,
    CONSTRAINT `fk_cart_product` FOREIGN KEY (`product_id`) REFERENCES `products` (`id`) ON DELETE CASCADE,
    CONSTRAINT `fk_cart_spec` FOREIGN KEY (`spec_id`) REFERENCES `product_specs` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='购物车表';
```

**设计说明**：
- `user_id + product_id + spec_id` 联合唯一，确保同一用户同一商品同一规格只存在一条记录
- 数量变更时更新 `quantity` 而非新增记录

### 2.6 订单主表 (`orders`)

存储订单核心信息。

```sql
CREATE TABLE `orders` (
    `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '订单ID',
    `order_no` VARCHAR(32) NOT NULL COMMENT '订单号(唯一)',
    
    -- 用户信息
    `user_id` BIGINT UNSIGNED NOT NULL COMMENT '用户ID',
    `user_nickname` VARCHAR(50) NOT NULL COMMENT '用户昵称(冗余)',
    
    -- 价格信息
    `total_amount` DECIMAL(10,2) NOT NULL COMMENT '商品总价',
    `discount_amount` DECIMAL(10,2) NOT NULL DEFAULT 0.00 COMMENT '优惠金额(会员折扣等)',
    `pay_amount` DECIMAL(10,2) NOT NULL COMMENT '实付金额',
    `balance_paid` DECIMAL(10,2) NOT NULL DEFAULT 0.00 COMMENT '储值支付金额',
    `points_deduct` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '积分抵扣数量',
    `points_deduct_amount` DECIMAL(10,2) NOT NULL DEFAULT 0.00 COMMENT '积分抵扣金额',
    
    -- 会员信息(下单时快照)
    `user_vip_level_id` VARCHAR(20) NOT NULL COMMENT '下单时会员等级ID',
    `user_vip_name` VARCHAR(20) NOT NULL COMMENT '下单时会员等级名称',
    `user_discount_rate` DECIMAL(3,2) NOT NULL DEFAULT 1.00 COMMENT '下单时会员折扣率',
    
    -- 取酒方式
    `pickup_method` VARCHAR(20) NOT NULL COMMENT '取酒方式(self-自取 delivery-配送)',
    `pickup_time` VARCHAR(50) NOT NULL DEFAULT '立即制作' COMMENT '取酒时间',
    
    -- 门店信息(冗余)
    `store_id` BIGINT UNSIGNED DEFAULT NULL COMMENT '门店ID',
    `store_name` VARCHAR(100) DEFAULT NULL COMMENT '门店名称',
    `store_address` VARCHAR(200) DEFAULT NULL COMMENT '门店地址',
    `store_phone` VARCHAR(20) DEFAULT NULL COMMENT '门店电话',
    
    -- 收货信息(如有配送)
    `receiver_name` VARCHAR(50) DEFAULT NULL COMMENT '收货人姓名',
    `receiver_phone` VARCHAR(20) DEFAULT NULL COMMENT '收货人电话',
    `receiver_address` VARCHAR(200) DEFAULT NULL COMMENT '收货地址',
    
    -- 订单状态
    `status` VARCHAR(20) NOT NULL COMMENT '订单状态',
    `status_text` VARCHAR(50) NOT NULL COMMENT '状态描述',
    
    -- 备注
    `remark` VARCHAR(200) DEFAULT NULL COMMENT '用户备注',
    `admin_remark` VARCHAR(200) DEFAULT NULL COMMENT '管理员备注',
    `cancel_reason` VARCHAR(200) DEFAULT NULL COMMENT '取消原因',
    
    -- 支付信息
    `pay_time` DATETIME DEFAULT NULL COMMENT '支付时间',
    `pay_method` VARCHAR(20) DEFAULT NULL COMMENT '支付方式',
    `transaction_id` VARCHAR(64) DEFAULT NULL COMMENT '微信支付订单号',
    
    -- 时间戳
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_order_no` (`order_no`),
    KEY `idx_user_id` (`user_id`),
    KEY `idx_status` (`status`),
    KEY `idx_created_at` (`created_at`),
    KEY `idx_pay_time` (`pay_time`),
    CONSTRAINT `fk_order_user` FOREIGN KEY (`user_id`) REFERENCES `users` (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='订单主表';
```

**订单状态流转**：

```
pending(待付款) → paid(已支付) → accepted(已接单) → making(制作中) → ready(待取酒) → completed(已完成)
                          ↓              ↓
                      cancelled(已取消)  cancelled(已取消)
                          ↓
                      refunded(已退款)  refunded(已退款)
```

**状态说明**：

| status | status_text | 说明 |
|--------|-------------|------|
| pending | 待付款 | 订单创建，等待用户支付 |
| paid | 待接单 | 用户已支付，等待商家接单 |
| accepted | 已接单 | 商家已接单 |
| making | 制作中 | 商品制作中 |
| ready | 待取酒 | 制作完成，等待用户取酒 |
| completed | 已完成 | 订单完成 |
| cancelled | 已取消 | 订单取消 |
| refunded | 已退款 | 已退款 |

### 2.7 订单明细表 (`order_items`)

存储订单中的商品明细。

```sql
CREATE TABLE `order_items` (
    `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '明细ID',
    `order_id` BIGINT UNSIGNED NOT NULL COMMENT '订单ID',
    `product_id` BIGINT UNSIGNED NOT NULL COMMENT '商品ID',
    `product_code` VARCHAR(20) NOT NULL COMMENT '商品编码(冗余)',
    `product_name` VARCHAR(100) NOT NULL COMMENT '商品名称(冗余)',
    `product_image` VARCHAR(500) NOT NULL COMMENT '商品图片(冗余快照)',
    
    -- 规格信息
    `spec_id` BIGINT UNSIGNED NOT NULL COMMENT '规格ID',
    `spec_name` VARCHAR(50) NOT NULL COMMENT '规格名称(冗余)',
    
    -- 价格信息
    `price` DECIMAL(10,2) NOT NULL COMMENT '单价(下单时)',
    `quantity` INT UNSIGNED NOT NULL DEFAULT 1 COMMENT '购买数量',
    `subtotal` DECIMAL(10,2) NOT NULL COMMENT '小计金额',
    
    -- 商品属性快照(可选)
    `abv` DECIMAL(3,1) DEFAULT NULL COMMENT '酒精度数快照',
    `brewery` VARCHAR(100) DEFAULT NULL COMMENT '酒厂快照',
    
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    
    PRIMARY KEY (`id`),
    KEY `idx_order_id` (`order_id`),
    KEY `idx_product_id` (`product_id`),
    CONSTRAINT `fk_item_order` FOREIGN KEY (`order_id`) REFERENCES `orders` (`id`) ON DELETE CASCADE,
    CONSTRAINT `fk_item_product` FOREIGN KEY (`product_id`) REFERENCES `products` (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='订单明细表';
```

**设计说明**：
- 所有商品信息存储快照（冗余），避免商品信息变更影响历史订单
- `subtotal = price * quantity`

### 2.9 充值套餐配置表 (`recharge_packages`)

存储充值套餐定义。

```sql
CREATE TABLE `recharge_packages` (
    `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '套餐ID',
```

## 四、业务规则

### 4.1 订单金额计算规则

```
商品总价 = SUM(order_item.price * order_item.quantity)
会员折扣 = 商品总价 * (1 - user.discount_rate)
实付金额 = 商品总价 - 会员折扣
积分获得 = 实付金额 * 1（每消费1元获得1积分）
成长值获得 = 实付金额 * 1（每消费1元获得1成长值）
```

### 4.2 充值规则

```
实际到账 = 充值金额 + 赠送金额
积分获得 = 充值金额对应的成长值 + 赠送金额
成长值获得 = 充值金额对应的成长值
```

### 4.3 会员等级计算

用户成长值变化后，自动计算并更新会员等级：
- 遍历 vip_levels 表，按 min_growth 升序
- 找到第一个满足 `growth_value >= min_growth AND growth_value < max_growth` 的等级
- 更新 users 表的 vip_level_id 和 vip_name 字段

### 4.4 库存管理

- 每次订单支付成功后，扣除对应规格的库存
- 商品表的总库存 = SUM(product_specs.stock)
- 库存不足时阻止下单

## 七、数据库维护建议

### 7.1 定期备份
- 建议每日凌晨2:00进行全量备份
- 交易高峰后进行增量备份

### 7.2 性能优化
- 订单表数据量大时考虑按月分表
- 定期清理 `consume_records` 历史数据
- 监控慢查询，优化索引

### 7.3 安全建议
- 生产环境禁止使用 root 账户
- 敏感字段（balance等）使用加密存储
- 定期更换数据库密码
